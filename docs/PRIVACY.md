# OhMyLockScreen 隐私政策

最后更新于 2026 年 11 月 13 日

本政策适用于 HelloWRC.Dev 发布的 OhMyLockScreen Windows 应用。应用在你的设备上处理运行锁屏和场景编辑器所需的数据。使用应用无需注册账户。应用不使用广告或使用情况追踪，也不会自动将下述数据上传给开发者或第三方。

## 应用读取哪些数据

- **锁屏与解锁。** 应用读取当前 Windows 用户的锁屏应用配置，并在你启用或关闭锁屏替换时更新该配置。应用只向 Windows 请求解锁，身份验证由 Windows 完成。应用不会读取或保存你的 Windows 密码、PIN 或 Windows Hello 生物识别数据。
- **场景内容。** 应用读取你选择或拖入的图片、视频，并在设备上保存副本，用于显示场景。场景配置也会保存你填写的文字和布局等设置。场景编辑器还会读取当前 Windows 锁屏图片作为编辑背景预览，不会将这张预览图片另存到场景。
- **当前媒体会话。** 使用媒体组件时，应用从 Windows 读取当前媒体会话的来源应用标识、标题、艺术家、专辑、封面、播放状态和进度等信息，用于显示媒体内容和提供播放控制。你操作播放控件时，应用通过 Windows 向当前媒体会话发送相应命令。应用不保存播放历史。
- **系统状态。** 使用相应组件时，应用读取电池电量和充电状态、系统输出音量和静音状态、当前网络的连接类型及名称（可能是 Wi‑Fi 名称），以及蓝牙开关和已连接设备数量。为避免重复计数，应用会在内存中处理蓝牙设备标识和地址。
- **音频频谱。** 使用频谱组件时，应用的本地辅助进程临时读取 Windows 正在播放的系统音频，在内存中计算频谱。组件通过当前会话中的应用包内管道接收频谱数据。此功能不访问麦克风，也不会将音频采样或频谱保存为文件。

## 数据保存与访问

应用将设置、场景配置和导入素材保存在 Windows 为当前用户分配的应用本地数据目录（`LocalState`）中。锁屏应用选择保存在当前用户的 Windows 配置中。媒体会话和系统状态组件的数据只在运行时使用。

锁屏设置操作可能在应用本地数据目录中留下诊断记录，例如操作时间、锁屏应用标识、配置变更结果和错误信息。调试版本还可能保存音频采集的运行状态和错误日志。应用不会自动提交这些诊断记录。

本地文件的访问由 Windows 文件权限管理。应用不会对场景配置或导入素材额外加密。将场景目录复制给他人时，目录中的设置和素材副本也会一同复制。

## 如何管理你的数据

- 你可以在场景编辑器中查看和修改已保存的场景，也可以移除媒体、系统状态或音频频谱组件。锁屏上显示的内容可能被能看到设备屏幕的人看到，你可以在场景中移除不想在锁屏上显示的内容。
- 移除或替换素材后，原有副本可能仍保留在场景目录中。删除场景会删除该场景的配置和素材副本。若要删除正在使用的场景，请先启用另一个场景。删除场景不会删除你导入时选择的原始文件。
- 你可以在应用中关闭锁屏替换，恢复 Windows 默认锁屏。若要清除设置、场景和诊断记录，可在 Windows 的应用设置中重置 OhMyLockScreen（如系统提供该选项），或卸载应用。你自行复制到其他位置的文件需要另行删除。

## 第三方服务与联系

Windows 和 Microsoft Store 对其自身处理的数据适用 [Microsoft 隐私声明](https://www.microsoft.com/zh-cn/privacy/privacystatement)。

如有隐私问题，可以通过项目的 GitHub 问题反馈页面联系维护者。该页面是公开渠道，请避免提交密码、私人素材或含个人信息的日志。[项目问题反馈](https://github.com/HelloWRC/OhMyLockScreen/issues)

如果应用的数据处理方式发生变化，更新后的政策会发布在本页，并注明更新日期。
